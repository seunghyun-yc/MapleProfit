# 메이플 사냥장부

소재비 횟수와 사냥 수익을 기록하는 메이플스토리 수익 계산기입니다.

## 설치 없이 바로 사용

**[메이플 사냥장부 열기](https://seunghyun-yc.github.io/MapleProfit/)**

다운로드·설치·로그인 없이 웹 주소를 열면 바로 사용할 수 있습니다.
웹 버전의 기록은 현재 브라우저의 IndexedDB에 저장되며 다른 사람에게 전송되지 않습니다.
같은 브라우저에서는 다시 접속해도 유지되지만, 다른 기기·브라우저와 자동 동기화되지 않습니다.
브라우저의 사이트 데이터를 삭제하거나 시크릿 창을 닫으면 기록이 사라질 수 있습니다.

아래 방법으로 자기 PC에서 직접 실행하는 것도 가능합니다. 직접 실행한 장부와 웹 장부는 별도의 저장소를 사용합니다.
ChatGPT·Cloudflare 계정이나 API 키가 필요하지 않습니다.

## 기능

- 소재비 횟수 `−`, `+`, `+1`, `+5`, 초기화 버튼
- 사냥으로 획득한 메소와 솔 에르다 조각 개수 입력
- 조각 1개 가격 직접 설정 및 기록별 가격 보존
- 경매장 수수료 선택: 없음 5%, MVP/PC방 3%
- 월별 총수익·메소·조각·소재비 합계, 일별 그래프
- 기록 수정 및 삭제

**수익 = 사냥 메소 + 조각 판매액 - 선택한 경매장 수수료**

경매장 수수료는 조각 판매액에서 차감합니다. 소비 비용은 반영하지 않으며 현금 수익을 의미하지 않습니다.

## PC에서 직접 실행하기 (선택)

1. [Node.js](https://nodejs.org/) 22.13 이상을 설치합니다. Node.js 22 계열을 권장합니다.
2. [GitHub 저장소](https://github.com/seunghyun-yc/MapleProfit)의 **Code → Download ZIP**으로 내려받아 압축을 풉니다. 또는 `git clone https://github.com/seunghyun-yc/MapleProfit.git`으로 복제합니다.
3. `package.json`이 있는 폴더에서 터미널을 열고 다음을 실행합니다.

```sh
npm ci
npm start
```

4. 준비가 끝나면 브라우저에서 **http://127.0.0.1:8787** 을 엽니다.

첫 설치에는 인터넷이 필요합니다. `npm start`는 사이트 준비와 로컬 저장소 생성을 자동으로 진행합니다.
이후에는 같은 폴더에서 `npm start`만 실행하면 됩니다. 종료는 터미널에서 `Ctrl+C`입니다.
종료해도 기록은 남습니다.

Windows, macOS, Linux에서 사용할 수 있는 실행 스크립트입니다. Windows에서는 PowerShell 또는 명령 프롬프트를 사용할 수 있습니다.
PowerShell에서 실행 정책 때문에 `npm`을 실행하지 못한다면 `npm.cmd ci`, `npm.cmd start`를 사용하세요.

## 직접 실행 버전의 저장과 백업

- 기록은 프로젝트 폴더의 **`.wrangler/state`**에 저장됩니다.
- 브라우저 새로고침이나 서버 재시작으로 사라지지 않습니다.
- 프로그램을 종료한 후 `.wrangler/state` 폴더 전체를 복사해 백업하세요.
- 다른 폴더에 새로 내려받으면 새 장부로 시작합니다. 기존 기록을 사용하려면 서버를 종료한 상태에서 같은 버전의 `.wrangler/state` 백업을 복원하세요.
- 저장소를 업데이트할 때 `.wrangler/state`를 지우지 마세요. 시작할 때 아직 적용되지 않은 저장소 변경만 적용됩니다.
- 개인 기록, 임시 파일, 계정 정보는 GitHub에 포함되지 않도록 제외되어 있습니다.

## 실행 옵션

```sh
# 다른 포트 사용
npm start -- --port=8790

# 개발 준비 및 화면 자동 갱신
npm run local:setup
npm run dev

# 타입 검사와 빌드
npm run typecheck
npm run build
```

개발 모드는 http://localhost:5173 에서 열립니다. 개발 모드와 일반 실행은 같은 로컬 기록을 사용합니다. 동시에 실행하지 마세요.

개발 검증은 별도의 시험용 사본에서 `npm start`로 서버를 연 후 `node scripts/smoke-test.mjs`를 실행합니다. 시험 기록은 삭제되지만 기본 조각 가격은 500만 메소로 바뀌므로 실제 장부에서는 실행하지 마세요.

## 사용 범위

웹 버전은 GitHub Pages에서 제공하며 기록은 방문자 각자의 브라우저에 저장합니다.
`npm start`로 직접 실행하는 버전은 해당 PC에서만 접속할 수 있는 개인용 서버입니다.
직접 실행하는 서버에는 사용자별 로그인과 기록 분리 기능이 없으므로 인터넷에 그대로 공개하는 공동 서버 용도로는 구성되어 있지 않습니다.

웹 버전을 수정했다면 `npm run build:web`로 만들고 `npm run preview:web`로 확인할 수 있습니다.
`main` 브랜치에 올리면 GitHub Actions가 웹 버전을 자동으로 게시합니다.
